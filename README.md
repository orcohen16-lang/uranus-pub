# Uranus Pub - האתר של אורנוס פאב

אתר סטטי בעברית ובאנגלית, עם וידאו ברקע, גלריה, קטעי ביקורות Google, חיוג ושמירת מקומות בווטסאפ.

## מבנה הקבצים

- `index.html` - עמוד האתר, כולל המלל בעברית.
- `style.css` - העיצוב והתאמות למובייל.
- `app.js` - מעבר השפה, תרגום לאנגלית, חלון התפריט ושליטה בווידאו.
- `assets/` - הלוגו, התמונות והווידאו שמופיעים באתר.
- `APPROVED_COPY.md` - המלל המאושר. אין לשנות ללא אישור.
- `REVIEW_SOURCES.md` - מקורות הביקורות ותאריך האימות.
- `.nojekyll` - מאפשר הגשה כאתר סטטי ב-GitHub Pages.

## העלאה ל-GitHub Pages

1. צרו repository ב-GitHub וחלצו אליו את תוכן ה-ZIP. `index.html` צריך להיות בשורש המאגר, ולא בתוך תיקייה נוספת.
2. העלו את הקבצים ל-branch בשם `main`.
3. היכנסו ל-Settings > Pages.
4. בחרו Deploy from a branch, ואז `main` ותיקיית `/(root)`, ולחצו Save.
5. לאחר השלמת הפרסום, GitHub יציג את כתובת האתר.

אפשר גם להעלות באמצעות Git מהמחשב, מתוך התיקייה שחילצתם:

```bash
git init
git add .
git commit -m "Add Uranus Pub website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

החליפו את כתובת המאגר בכתובת האמיתית שלכם. החבילה אינה יוצרת מאגר או מפרסמת אותו בעצמה.

## צפייה מקומית

אין צורך בהתקנה או בבנייה. הפעילו מתוך תיקיית האתר:

```bash
python3 -m http.server 8000
```

ופתחו `http://localhost:8000` בדפדפן.

## מצב הטיוטה

- התפריט מצורף כקובץ PDF ב־`assets/uranus-menu.pdf` ומקושר מההדר ומאזור שעות הפתיחה.
- תמונת הבמה הפתוחה נמצאת ב-`assets/open-stage.png`.
- הביקורות והדירוג הם צילום מצב שנבדק ב-17.11.2026, ללא עדכון אוטומטי.
- נשמרו סימוני הטיוטה ותגית `noindex,nofollow` המקוריים. כשהאתר מוכן לחשיפה במנועי חיפוש, הסירו את תגית `meta name="robots"` מ-`index.html` ואת סימוני הטיוטה הרצויים.
- הפונט נטען מ-Google Fonts; ללא חיבור לאינטרנט יופיע פונט חלופי.
- מנגנון ההתחברות של Sites אינו חלק מהקוד. GitHub Pages לא ידרוש כניסה ל-ChatGPT.
- תמונות, לוגו ווידאו נמסרו על ידי בעל הפרויקט. לא נוספה רישיון קוד פתוח לחבילה.

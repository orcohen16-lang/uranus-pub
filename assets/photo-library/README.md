# Uranus photo library

זוהי ספריית התמונות היחידה של האתר. קובצי תמונה כפולים מתיקיית `assets` וקובצי ה־ZIP המקוריים הוסרו לאחר אימות.

## סליידר ראשון

בתיקייה `סליידר ראשון` נמצאות עשר התמונות שנבחרו לסליידר האוכל והשתייה. כולן בפורמט WebP, בגודל 1080×1350 וביחס 4:5.

סדר ההצגה באתר נקבע לפי המספר שבשם הקובץ, מ־`slide-01` עד `slide-10`.

## גלריית אווירה

בתיקייה `best 10` נמצאות בדיוק עשר התמונות שנבחרו לפסיפס האווירה שבתחתית העמוד. כולן בפורמט WebP ומסודרות באתר כך שיופיע שילוב של אנשים, אוכל, שתייה ופרטי פאב.

התמונות שנמצאות ישירות בתיקייה זו משמשות לאזור ה־Happy Hour, לבמה הפתוחה, לפוסטר הווידאו ולכפתור Waze. תמונות הצילום הומרו ל־WebP; לוגו Waze נשמר כ־PNG כדי לשמור על הרקע השקוף.

הווידאו והלוגו נשארו בתיקיית `assets`, משום שאינם חלק מספריית צילומי התוכן.
